Part A · Antigravity: an agent writes, you review (30 pts)

  1. Create an empty folder fef3001-a1 and open it in Antigravity. Download SPEC.md into that folder.
  2. In the agent settings, set the review policy so that the agent must request review before it acts. You are the reviewer: nothing is written without your approval.
  3. Ask the agent, in your own words, to implement co2_analysis.py and test_co2_analysis.py exactly as specified in SPEC.md.
  4. Read the agent's implementation plan before approving it. Leave at least one substantive comment on the plan (a real question or correction — not “looks good”) and see how the agent responds.
  5. Run the tests in the terminal: python -m pytest -q. All tests must pass.
  6. Write one more test yourself, by hand, that the agent did not write, and make it pass.
  7. Keep, for the submission: a screenshot or PDF of the plan with your comment, the agent's walkthrough, and the terminal showing the passing tests.

Open the starter notebook, choose File → Save a copy in Drive, and upload your co2_analysis.py when the first cell asks for it. Run everything, complete each TODO and answer in the Your answer cells:
